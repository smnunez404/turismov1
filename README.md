# Soy Embajador Bolivia

Aplicación web gamificada para el aprendizaje turístico y cultural de Santa Cruz de la Sierra, Bolivia.

## Características Principales
- **Modalidades de Juego:** Partida Rápida (5 mecánicas), Ruleta Cruceña, Reto Diario (por fecha), Sopa de Letras, Verdad o Reto y Duelos 1v1.
- **Liguillas Privadas con PIN:** Torneos grupales cerrados tipo Kahoot diseñados para colegios, universidades y grupos de amigos.
- **Camino de Temporada (Pase Cruceño):** Progresión por hitos de 10 a 100 puntos con desbloqueo de cofres chiquitanos, recompensas y piezas exclusivas de avatar.
- **Modo Historia Inmersivo:** Diapositivas narrativas paso a paso con ilustraciones de la expedición de Ñuflo de Chaves y la fundación de Santa Cruz.
- **Premios y Beneficios Reales:** Gancho promocional interactivo con cupones para cine, combos gastronómicos típicos, tours chiquitanos y becas.
- **Diseño Visual:** Interfaz móvil responsiva basada en la identidad *Selva Vibrante* e iconografía vectorial SVG limpia.

## Tecnologías Utilizadas
- [React 19](https://react.dev)
- [TanStack Start & Router](https://tanstack.com)
- [Tailwind CSS](https://tailwindcss.com)
- [Lucide Icons](https://lucide.dev)
- [Nitro Engine](https://nitro.unjs.io)

## Instalación y Ejecución Local

Para ejecutar el proyecto en tu entorno local:

```bash
# 1. Clonar el repositorio
git clone https://github.com/smnunez404/turismov1.git
cd turismov1

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev
```

La aplicación estará disponible en `http://localhost:8080/`.

## Compilación para Producción

```bash
npm run build
npm run preview
```
