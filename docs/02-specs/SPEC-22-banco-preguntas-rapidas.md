# SPEC-22 — Banco de preguntas rápidas

Archivo: `src/data/preguntas-rapidas.ts` · Sprint: S-5 · Estado: Hecho

## Objetivo
Contenido sintético para el modo rápido, separado del banco narrativo de las misiones.

## Estructura
- 36 preguntas, 6 por categoría.
- Cada ítem: enunciado, 4 opciones, respuesta correcta y retroalimentación breve.
- Tono cruceño, sin tecnicismos, con dato memorable en la retroalimentación.

## Criterios de aceptación
- [x] Todas las categorías tienen al menos 6 preguntas para una tanda completa.
- [x] Cada pregunta tiene retroalimentación, tanto para acierto como para error.
- [x] Los datos son sintéticos y revisables por la cliente antes de producción.
