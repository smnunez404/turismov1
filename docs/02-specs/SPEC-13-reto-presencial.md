# SPEC-13 — Reto presencial (Misión 5)

- **Pantalla:** P-13 (`/mision/$misionId/reto`) · **Sprint:** S-3 · **Estado:** Hecho — verificado 28-08-2026

**Propósito.** Representar el paso del aprendizaje a una acción presencial sin implementar una
plataforma de carga o publicación.

**Comportamiento.** La pantalla propone visitar un lugar, permite elegir una imagen del
dispositivo y genera una vista previa local mediante `FileReader`. La selección de acompañantes
y la confirmación son simulaciones de sesión.

**Criterios de aceptación**

- [x] La imagen elegida se previsualiza localmente.
- [x] El archivo no se sube, persiste, publica ni envía.
- [x] La pantalla explica que la foto no sale del navegador.
- [x] La acción esperada en el mundo real y la selección demo de acompañantes son claras.
