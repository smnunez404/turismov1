# SPEC-14 — Perfil del usuario

- **Pantalla:** P-14 · **Sprint:** S-3 · **Estado:** Hecho (28 de agosto de 2026)

**Propósito.** Espejo del progreso e identidad del usuario.

**Comportamiento.** Avatar, nivel, puntos acumulados, álbum, cosméticos, insignias obtenidas
(con las bloqueadas visibles en estado apagado) y progreso de la temporada.

**Criterios de aceptación**

- [x] Las insignias no obtenidas se ven, pero apagadas.
- [x] Los datos reflejan el estado real de la sesión.
- [x] El álbum muestra en contenido visible el nombre y el estado o requisito de cada estampa;
      no depende de `title` ni de hover.
- [x] Álbum, estadísticas, nivel, correo y etiquetas permiten ajuste de línea sin desbordarse a
      320 px.
- [x] Los enlaces compactos de edición y álbum conservan un área táctil mínima de 44 px.
