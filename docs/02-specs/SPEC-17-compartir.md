# SPEC-17 — Preparar tarjeta e invitaciones demo

- **Pantalla:** P-17 (`/compartir`) · **Sprint:** S-4 · **Estado:** Hecho — verificado 28-08-2026

**Propósito.** Representar el cierre del ciclo de aprendiz a promotor sin fingir una publicación
real.

**Comportamiento.** Prepara una tarjeta visual y permite confirmar invitaciones simuladas. No
invoca Web Share, redes sociales, descarga, mensajería ni APIs externas. La confirmación puede
otorgar una insignia demo en el estado local.

**Criterios de aceptación**

- [x] La pantalla declara que no publica ni envía datos reales.
- [x] La acción se nombra como preparación o simulación.
- [x] La insignia se aplica sólo después de confirmar la simulación.
- [x] Todo el estado desaparece al recargar.
